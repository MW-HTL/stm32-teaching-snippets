# STM32 LS1 – Hello STM32

Beispielprojekt für DIC3.

Hardware:
- LEOboard
- STM32G474VET6

## Aufgabe

1. Repository herunterladen bzw. klonen.
2. Projektordner in Visual Studio Code öffnen.
3. Projekt compilieren.
4. LEOboard über ST-LINK verbinden.
5. Programm auf den STM32 übertragen.

Wenn alles funktioniert, blinkt die LED.

Noch nicht alles im Projekt verstanden?

Das ist völlig in Ordnung. Genau darum geht es in dieser Lernstrecke.
